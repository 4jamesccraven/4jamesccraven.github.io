ser_nix

github crates.io docs (latest)

ser_nix is a Rust crate utilising the serde frame work that allows users to serialise structs into Nix code. This enables automated generation of syntactically valid Nix data types, allowing developers to integrate Rust data with reproducible workflows without manually writing tedious and potentially buggy boilerplate.

mkdev

github crates.io wiki

mkdev is a command line templating engine designed to streamline starting new projects. It works by saving the contents of the current working directory into a recipe file that it can later use to re-deploy said recipe as many times as needed. Mkdev can also do templating inside the source files themselves by calling out to child processes defined by the user in a config file.
